## Refresh

The FoSCoS page is an Angular app, so `source.html` contains the app shell and `rendered.md` contains the rendered manual list captured with Tavily.

```bash
tvly extract "https://foscos.fssai.gov.in/user-manual" --extract-depth advanced --include-images -o document_cache/foscos_user_manual/rendered.md
python3 tools/cache_foscos_user_manual.py
```
